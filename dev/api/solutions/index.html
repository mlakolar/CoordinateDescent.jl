Solutions and StatsAPI

StatsAPI.coef — Method
coef(sol::LassoSolution)

The coefficients as a SparseVector: [β₀; β], the intercept first, when the solver fitted an intercept, and β otherwise, so that they line up with a model matrix whose first column is the constant.

source
StatsAPI.coef — Method
coef(path::LassoPath)
coef(path::LassoPath, λ)

The coefficients along the path, as a sparse matrix with one column per value of path.λpath, whose first row holds the intercepts when the path has an intercept. With λ, the coefficients at λ as a SparseVector, interpolated linearly in λ between the two neighboring values of λpath (as glmnet's coef(fit, s = λ)), and exact at the values of λpath; λ must be within the range of λpath.

source
StatsAPI.deviance — Method
deviance(sol::LassoSolution)

The residual sum of squares ‖y - β₀ - X * β‖², weighted, ∑ᵢ wᵢ rᵢ², for a fit with observation weights.

source
StatsAPI.dof — Method
dof(sol::LassoSolution)

The number of nonzero coefficients, plus one for an intercept: an unbiased estimate of the degrees of freedom of the lasso (Zou, Hastie and Tibshirani, On the "degrees of freedom" of the lasso, 2007). For the elastic net, MCP and SCAD it is the count that glmnet and ncvreg report, not an unbiased estimate.

source
StatsAPI.fit — Method
fit(LassoPath, X, y, args...; kwargs...)

The same as LassoPath(X, y, args...; kwargs...).

source
StatsAPI.nobs — Method
nobs(sol::LassoSolution)
nobs(path::LassoPath)

The number of observations the solver was given.

source
StatsAPI.predict — Method
predict(sol::LassoSolution, X)

The fitted values β₀ .+ X * β at the rows of X, which has the columns of the data the solver was given (without a column for the intercept); an offset of the fit is not included.

source
StatsAPI.predict — Method
predict(path::LassoPath, X)

The fitted values β₀ .+ X * β along the path: a matrix with one column per value of path.λpath.

source
StatsAPI.residuals — Method
residuals(sol::LassoSolution)

The residuals y - β₀ - X * β of the data the solver was given. A solution computed from sufficient statistics (scaledLasso! with a CDSqrtQuadraticLoss) has none, and an error is thrown; so it is for nobs and deviance.
