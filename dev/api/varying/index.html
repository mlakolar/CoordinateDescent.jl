Varying-coefficient models

CoordinateDescent.EpanechnikovKernel — Type
EpanechnikovKernel(h)

Epanechnikov kernel K_h(x, y) = 0.75 (1 - u²) / h for |u| < 1 and zero otherwise, where u = (x - y) / h.

source
CoordinateDescent.GaussianKernel — Type
GaussianKernel(h)

Gaussian kernel K_h(x, y) = exp(-(x - y)² / h) / h.

Note that h enters as a variance (h = 2σ²), not as a standard deviation.

source
CoordinateDescent.SmoothingKernel — Type
SmoothingKernel{T}

Supertype of kernels K_h(x, y) with bandwidth h used to weight observations in local polynomial regression. Evaluate with evaluate.

CoordinateDescent.getStandardError — Method
getStandardError(X, z, σ2, z0, degree, kernel)

Variances of the local polynomial estimates β̂ⱼ(z0), j = 1, ..., p, under homoscedastic noise with variance σ2. With W = diag(K_h(zᵢ, z0)) and the expanded design X̃, the covariance of the estimator is

σ2 (X̃'WX̃)⁻¹ X̃'W²X̃ (X̃'WX̃)⁻¹

and the function returns the diagonal entries that correspond to β̂ⱼ(z0). Take square roots to obtain standard errors.

source
CoordinateDescent.getStandardErrorHEW — Method
getStandardErrorHEW(X, z, ϵ_sqr, z0, degree, kernel)

Heteroscedasticity-robust (Eicker–Huber–White) version of getStandardError: the variances of β̂ⱼ(z0) computed from

(X̃'WX̃)⁻¹ X̃'W Ψ W X̃ (X̃'WX̃)⁻¹,   Ψ = diag(ϵ_sqr),

where ϵ_sqr holds squared residuals, for example from getResiduals!.

CoordinateDescent.locpoly — Method
locpoly(X, z, y, z0::Real, degree, kernel=GaussianKernel(1))
locpoly(X, z, y, zgrid::Vector, degree, kernel=GaussianKernel(1))

Local polynomial estimate of the varying-coefficient model yᵢ = ∑ⱼ Xᵢⱼ βⱼ(zᵢ) + εᵢ at z0, or at every point of zgrid.

At z0 it solves the weighted least squares problem

minimize  ∑ᵢ K_h(zᵢ, z0) (yᵢ - X̃ᵢ'β)²

with X̃ᵢ = Xᵢ ⊗ [1, (zᵢ - z0), ..., (zᵢ - z0)^degree]. Returns the coefficient vector of length p(degree + 1), or a matrix with one such column per grid point. Coefficient (j-1)(degree+1) + 1 is the estimate of βⱼ(z0).

The data can be arrays of any type with real entries, such as views, and zgrid a range; they are converted to the floating point type of X, z and y, and so is the kernel.

source
CoordinateDescent.locpolyl1 — Method
locpolyl1(X, z, y, zgrid, degree, kernel, λ0, refit, options=CDOptions())

Local polynomial estimate of a sparse varying-coefficient model at each point z0 of zgrid. At z0 it solves the weighted lasso

minimize  ∑ᵢ wᵢ (yᵢ - X̃ᵢ'β)² / (2n) + λ0 ∑ₖ sₖ |βₖ|

where wᵢ = K_h(zᵢ, z0), X̃ᵢ = Xᵢ ⊗ [1, (zᵢ - z0), ..., (zᵢ - z0)^degree] and sₖ = sqrt(∑ᵢ wᵢ X̃ᵢₖ² / n) standardizes the columns of the expanded design. Each problem is warm started from the solution at the previous grid point.

The loss scales with the kernel and the loadings sₖ with its square root, so λ0 is on the scale of the kernel: multiplying the kernel by a constant c gives the same estimate when λ0 is multiplied by √c.

Returns (B, BR), sparse matrices of size p(degree + 1) × length(zgrid). Column k of B holds the lasso estimate at zgrid[k]. If refit is true, column k of BR holds the weighted least squares refit on the selected variables (all degree + 1 coefficients of a variable are refit when any of them is nonzero, and the refit of minimum norm is taken when it is not unique); otherwise BR is zero.

X, z, y and zgrid can be arrays of any type with real entries, such as views or ranges; they are converted to the floating point type of X, z and y, and so are the kernel and λ0.

source
CoordinateDescent.lvocv_locpolyl1 — Method
lvocv_locpolyl1(X, z, y, degree, hArr, KernelType, λ0, options=CDOptions())

Leave-one-out cross-validation error of the refitted locpolyl1 estimator for each bandwidth in hArr.

For each observation i, the model is fit at z0 = zᵢ with observation i given zero weight. The lasso penalty is λ0 σ̂, where the noise level σ̂ is estimated jointly with the coefficients as in the scaled lasso. The selected variables are refit by weighted least squares, taking the refit of minimum norm when it is not unique, and used to predict yᵢ. As in locpolyl1, λ0 is on the scale of the kernel.

Returns the vector of summed squared prediction errors, one per bandwidth. As for locpolyl1, the data can be arrays of any type with real entries. KernelType can be given with or without its parameter, as GaussianKernel{Float64} or GaussianKernel.

source
CoordinateDescent.refit_locpolyl1 — Method
refit_locpolyl1(X, z, y, z0, degree, kernel, β)

Refit the local polynomial estimate at z0 using only the variables selected by β, the expanded coefficient vector returned by locpolyl1 at z0. A variable is selected when any of its degree + 1 coefficients is nonzero.

Returns (βr, S), where S is a BitVector of length p marking the selected variables and βr is the locpoly estimate on X[:, S].
