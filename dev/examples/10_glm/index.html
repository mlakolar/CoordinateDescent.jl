Penalized generalized linear models

glm_lasso(X, y, λ, loss = ProximalBase.Logistic(), options = CDOptions();
         intercept = true, standardize_x = true, weights, offset)
GLMLassoPath(X, y, loss = ProximalBase.Logistic(); nλ = 100, λminratio, kwargs...)

minimize ∑ᵢ wᵢ ℓ(β₀ + xᵢ'β + oᵢ, yᵢ) / ∑ᵢ wᵢ + λ ∑ⱼ ωⱼ |βⱼ| for a scalar loss ℓ of ProximalBase, with glmnet's conventions and defaults: an unpenalized intercept, loadings ωⱼ equal to the standard deviations of the columns, observation weights w and an offset o. They run proximal Newton (glmnet's method): each step minimizes the weighted least-squares model of the loss by coordinate descent, then backtracks.

using CoordinateDescent, ProximalBase
using LinearAlgebra, Printf, Random, Statistics

Random.seed!(10)
logistic(z) = 1 / (1 + exp(-z))

β = zeros(p)

y = Float64.(rand(n) .< logistic.(-0.5 .+ X * β))
support(x) = findall(!iszero, x)

function deviance(η, y)
  2 * sum(log1p.(exp.(η)) .- y .* η)
end

Poisson regression with an exposure offset

Poisson draws by Knuth's method, to avoid a dependency on Distributions

function rpois(μ)
  k, t, L = 0, rand(), exp(-μ)
  while t > L
    k += 1
    t *= rand()
  end
  k
end
exposure = rand(n) .* 4 .+ 1
counts = Float64.(rpois.(exposure .* exp.(0.2 .+ 0.4 .* X[:, 1] .- 0.3 .* X[:, 2])))
