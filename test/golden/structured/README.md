genlasso 1.6.1 and glmgen 0.0.3 at commit
`9e6061503d6dd103712a0c07f6be7293c1c58aaf`.
`provenance.txt` records R and dependency versions. Seeds are 8101–8103.
The four levels use `lambda_R = n * lambda_Julia`.

The genlasso fits are evaluated along its complete exact paths. Coefficients
and degrees of freedom cover fused regression, cyclic graph regression, and
trend orders 0–3 on unit and irregular locations. Glmgen supplies a second
trend-filtering reference. CI reads these fixed fixtures and needs no R
installation.

## Regeneration

From the repository root, with the master test environment built by
`julia scripts/test_master.jl --setup-only` (it provides the package and
`Test`; `LinearAlgebra` is a standard library), R 4.5.3, and an R library
`$RLIB`:

```sh
mkdir -p "$RLIB"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
R_LIBS=$RLIB Rscript test/golden/structured/setup.R
R_LIBS=$RLIB Rscript test/golden/structured/golden.R test/golden/structured
julia --startup-file=no --project=.master-test-env/v1.13 test/golden/structured/check_golden.jl test/golden/structured
```

`setup.R` installs `remotes`, then genlasso 1.6.1 from CRAN
(`remotes::install_version`) and glmgen from GitHub at the commit above
(`remotes::install_github`, R package subdirectory `R_pkg/glmgen`), and stops
if either is missing or has another version. `golden.R OUT` writes the
fixtures and `provenance.txt` into `OUT`; `check_golden.jl OUT` runs
`test/structured_golden.jl` against them. Another `OUT` leaves the fixtures
unchanged.
