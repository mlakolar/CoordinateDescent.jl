# R golden data for selection procedures

Generated by `golden.R` in this directory with R 4.5.3, SLOPE 2.1.1,
knockoff 0.3.6, stabs 0.7.1 and glmnet 5.1 (see R-session.txt).
Inputs use seed 8203; Gaussian innovations use seed 8204. Fixed pairs are
saved in folds.csv. Julia reads these files in test/selection_golden.jl;
R is not needed to run the tests.

SLOPE uses gamma=1 (regularized fits), shared penalty multipliers and matched
preprocessing. Without an intercept, RMS scaling is explicit because R's SD
scaling uses centered variances whereas this package uses uncentered mean
squares. Gaussian knockoffs share both s and the normal innovations. Fixed-X
comparison uses Gram identities because orthogonal bases differ. R's adaptive
PSD safety adjustment can change the equicorrelated diagonal by about 1e-7;
the diagonal comparison therefore uses a 2e-7 maximum absolute tolerance.
Stability selection uses the shared fixed-lambda capped lasso selector.

## Regeneration

From the repository root, with the master test environment built by
`julia scripts/test_master.jl --setup-only` (it provides the package,
`DelimitedFiles` and `Test`; `LinearAlgebra` and `Random` are standard
libraries), R 4.5.3, and `SELECTION_RLIB` naming a writable R library:

```sh
export SELECTION_RLIB=/path/to/rlib OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
Rscript test/data/selection/setup.R
Rscript test/data/selection/golden.R test/data/selection
julia --startup-file=no --project=.master-test-env/v1.13 test/data/selection/golden.jl test/data/selection
```

`setup.R` installs SLOPE, knockoff, stabs and glmnet from CRAN into
`SELECTION_RLIB` when they are missing and prints the installed versions.
Replace any that differ from the recorded versions, for example with
`remotes::install_version("stabs", "0.7-1", lib = Sys.getenv("SELECTION_RLIB"), repos = "https://cloud.r-project.org")`.
`golden.R OUT` writes the inputs, the R references and R-session.txt into
`OUT`; `golden.jl OUT` runs test/selection_golden.jl against them. Another
`OUT` leaves the fixtures unchanged.
