# rrpack golden data

Generated by `oracle.jl generate` and `oracle.R` in this directory, in run
`20261025T0910Z-cd81`, with R 4.5.2 and rrpack 0.1-14. Seeds 8101–8103
produce three Gaussian designs, with rank-two signal and sparse predictor
rows. `X*.csv` and `Y*.csv` are shared inputs; the other CSVs are independent
R outputs, read directly by `test/lowrank_golden.jl`.
The test suite needs no R installation.

RRR compares coefficients on identifiable designs and fitted values for the
wide design: rrpack returns basic QR coefficients, while this implementation
returns the minimum-norm coefficients. `df-*.csv` contains exact Stein degrees
of freedom. SRRR uses three penalties with unit/adaptive weights and an
explicit common RRR initialization; rrpack's level is `n*λ`.

RSSVD uses ten penalty candidates and actual BIC selection. rrpack 0.1-14
swaps BIC/BICP selection labels inside `rssvd.eea`; the oracle script requests
its BICP label and verifies the selected coefficients against the BIC column
of the independent R path. The Julia methods use the documented formulas.
The component-level diagnostic agreed within 3.1e-9 before model selection.

## Regeneration

From the repository root, with the master test environment built by
`julia scripts/test_master.jl --setup-only` (it provides the package,
`DelimitedFiles` and `Test`; `LinearAlgebra`, `Printf` and `Random` are
standard libraries) and an R library `$RLIB` holding rrpack 0.1-14 for R 4.5.2:

```sh
mkdir -p "$RLIB"
R_LIBS=$RLIB Rscript -e 'install.packages("remotes", repos = "https://cloud.r-project.org")' \
  -e 'remotes::install_version("rrpack", "0.1-14", repos = "https://cloud.r-project.org")'
julia --startup-file=no --project=.master-test-env/v1.13 test/data/lowrank/oracle.jl generate test/data/lowrank
R_LIBS=$RLIB Rscript test/data/lowrank/oracle.R test/data/lowrank
julia --startup-file=no --project=.master-test-env/v1.13 test/data/lowrank/oracle.jl compare test/data/lowrank
```

`oracle.jl generate DIR` writes the shared inputs `X*.csv` and `Y*.csv` into
`DIR`; `oracle.R DIR` writes the R fits there, together with
`rrpack-version.txt`, which is not part of the fixtures. `oracle.jl compare DIR`
checks the package against those fits and prints the largest errors. Another
`DIR` leaves the fixtures unchanged.
