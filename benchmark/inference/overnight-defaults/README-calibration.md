# Logistic calibrated-nuisance pilot

Experimental adaptation of Appendix A4 in Liu, Zhang and Zhou (2021), Econometrics Journal24,559–588, https://pmc.ncbi.nlm.nih.gov/articles/PMC10786638/ . The target is a conditional logistic coefficient. No ATE substitution.

Use native glmnet5.1 and RCAL2.0. Fit initial logistic coefficients, a weighted target regression among controls, a preliminary scalar score root, a weighted calibrated outcome regression with target offset, and the final calibrated score root. Identity link for the target nuisance. All penalties use eight geometric levels over[.2,2]sqrt(log(p)/n),five folds,original predictor units. RCAL/glmnet normalize sample weights; penalties are stated in those native normalized units. Both minimum-CV and1SE calibration penalties are retained. Exact author replication code was not retrieved, so this is a formula-based adaptation.

Check initial/auxiliary/calibrated KKT residuals, negative scalar derivative, finite-difference derivative agreement, root residual and complete requested target sets. Exclude nonconverged CV levels from selection; preserve counts and warnings. Intervals use the empirical score sandwich and normal quantiles. The paper uses bootstrap intervals; this pilot does not claim to reproduce its confidence-interval procedure or published coverage table. No defaults change from this development study.

Reuse ten existing logistic designs and seeds on matched saved input data. Add a class-conditional Gaussian positive control based on Appendix A5(i):200Gaussian controls plus the distinguished predictor,n1000,alpha.5. The precision diagonal is1.5 for the target and1.2 otherwise; target correlations in precision are.2 for the first four controls. Class1 mean(.4,-.25,-.25,0,...),class0 mean0,equal class probabilities. Bayes' rule gives coefficient vector P*mu and intercept-.155; retain that intercept. Only alpha and five nulls are requested. The n200 version is a new stress extension. These details resolve intercept/constant notation explicitly and are not claimed an exact code-level replica. New-design seeds use93000000canary/94000000development plus case offsets; existing cases retain their matched920/921 input namespaces. Confirmation92200000 remains untouched.

All fitting and numerical summaries run on Discovery compute nodes. The source snapshot is immutable. Track package installation, failures, raw coefficients, complete-dataset reliability and dataset-level Monte Carlo errors. Assess target roles, not changing physical column labels in random-support designs. Freeze a policy before fresh confirmation.

Target-parallel runner `calibrated-logistic-targets.R` changes orchestration only. The statistical helper block is byte-identical to `calibrated-logistic.R`; `calibration-core-sha256.txt` records its hash. It reuses a target only when both policies and diagnostic rows are complete, finite, converged, and no target error exists. Partial and failed v1 targets remain preserved. The original serial canary was cancelled after 674 seconds to avoid serializing expensive targets. No statistical parameter was changed.
